# Tomman

## Tomman demo: Bootswatch Paper replica, light-only, Indonesian-only
Miniature of the legacy Tomman app (reference: d:\ISH\tomman1_trial_rezaftyan, read-only — never edit it). Laravel 5.4 + Bootstrap 3 via **Bootswatch "paper"** 3.3.6, jQuery, no build step. Each page is a standalone HTML doc — no shared layout.

- **No dark mode and no language switcher, deliberately** — the real app has neither. Light mode + Indonesian only. Do not add `data-theme`, `#langSwitch`, or localStorage theme/lang keys here.
- Palette is sampled from `public/bower_components/bootswatch-dist/css/bootstrap.min.css` (paper), not invented: Roboto 13px/1.846, body text `#666`, headings `#444`, strong `#212121`, primary `#2196f3` (hover `#0c7cd5`), success `#4caf50`, danger `#e51c23`, warning `#ff9800`, border `#ddd`, stripe `#f9f9f9`, radius 3px, navbar white min-height 64px. `layout.blade.php` then overrides: body `#e2e2e2`, h3 24px, navbar `box-shadow:0 1px 10px rgba(0,0,0,.3)` + `margin-bottom:10px`, navbar-nav `font-size:11px`, `.btn-info` repainted to `#FF5442`, `.label-info` to `#2196f3`, `.nav-tabs` gets `border:1px solid #D6D6D6`. Brand is `<span class="redxxx">TOM</span>MAN` with red `#e74c3c`.
- Paper inputs are **material underline**, not boxes: `.form-control` is transparent with `box-shadow:inset 0 -1px 0 #ddd`, focus `inset 0 -2px 0 #2196f3`, font-size 16px, no border, no radius. Getting this wrong is the fastest way to make the skin look like plain Bootstrap.
- Markup keeps the real Bootstrap 3 class names (`panel panel-primary`, `table table-striped table-bordered`, `label label-danger`, `nav nav-tabs`) so screens can be copied from the source views almost verbatim. `partials/shell-styles.blade.php` hand-implements those classes — add overrides there, never fork per page.
- `partials/wo-data.blade.php` is the single dummy deck every screen shares (TIM, SEKTOR, WOS, STATUS). All numbers come from the deterministic `seeded()` hash, never `Math.random()`, so matrices and drill-downs stay stable across re-renders. Timestamps must come out of the WITA (`Asia/Makassar`) formatters in that file — the real app calls `date_default_timezone_set('Asia/Makassar')`; never mix in the viewer's local clock.
- `status_laporan` ids and chip colours follow `dispatch/matrix.blade.php`'s branch ladder exactly (1/37 success, 5 warning, 4 info, 6/null default, 7 darkgrey, 28/29 bluepas, 31 purple, 43/44 black, 45/46/48 coklat, 50 golden, everything else danger). The four matrix counters come from `bucketOf()`; status 4 counts as NO UPDATE because the real view derives it by subtraction.
- **The navbar carries only entries that resolve to a screen here.** An earlier revision reproduced the real app's full level-2 menu tree with the unimplemented items raising a "not built" toast; the user rejected that on 2026-09-23 — a menu item that goes nowhere reads as a broken app, not as fidelity. When a new screen is added, add its entry then; never re-introduce placeholder menu items. Deliberate deviation from the source nav: the Telegram broadcast (`/attention`, unlinked in the real app) gets its own top-level entry so the bot-automation feature is reachable.
- `data-demo` is therefore only for **in-screen action chips** the real app posts to a controller (Hapus, Send SMS, Update MS2N, Send To KPRO…). Those stay — they are most of what a workorder row looks like — and the shared handler in `partials/shell-script.blade.php` answers them with "aksi ini tidak terhubung ke server sungguhan".
- **Dispatch vs Re-Dispatch is keyed off the regu, never off the report status.** `workorderlist.blade.php` branches on `id_r` and `assurance/index.blade.php` on `uraian`: empty → a lone "Dispatch" chip, filled → the team name + mitra + dispatch stamp + "Re-Dispatch". So the deck carries genuinely unassigned orders (`tim`/`sektor`/`mitra`/`dispatch_at` all `''`, status pinned to 6); `woOf()` guards against `''` so they never leak into the matrix, and the ticketing UNDISPATCH row counts `!w.tim`, not `status === 6`. Both chips open `partials/dispatch-modal.blade.php` (a stand-in for `/dispatch/{orderId}`), and saving really calls `dispatchWo()` to mutate the shared deck and re-render — this is a working action, not a toast.
- Toast lives at `bottom:62px` on purpose: the portfolio demo badge is fixed at `bottom:14px` with a higher z-index, and overlapping the two made every action look dead.
- **Never write raw `{{ … }}` inside these files**, not even quoting the source app inside a JS comment — Blade evaluates it and the page 500s. Describe the original expression in prose, or escape it as `@{{ … }}`.
